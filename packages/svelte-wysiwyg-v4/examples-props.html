🧩 Component Props

Interactive configuration of all WysiwygEditor component props

Usage

The WysiwygEditor component accepts props that map directly to Jodit configuration options.

Dynamic Props

Can be changed at runtime:

  • disabled - Completely disable the editor
  • readonly - Content visible but not editable

Static Props

Set at initialization (recreate editor to change):

  • height, width - Dimensions
  • theme - 'default' or 'dark'
  • placeholder - Empty state text
  • toolbar, statusbar - UI visibility
