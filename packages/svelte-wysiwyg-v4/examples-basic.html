Keyboard Navigation

The editor supports standard text editing keyboard shortcuts in both WYSIWYG and Source modes.

WYSIWYG Mode

  • Ctrl+B - Bold
  • Ctrl+I - Italic
  • Ctrl+U - Underline
  • Ctrl+Z - Undo
  • Ctrl+Y - Redo

Source Mode (Ace)

  • Tab - Indent
  • Shift+Tab - Outdent
  • Ctrl+/ - Toggle comment
  • Ctrl+F - Find
  • Ctrl+H - Find and replace
