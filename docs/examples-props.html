🧩 Component Props

Interactive configuration of all JoditEditor component props

Usage

The JoditEditor component accepts props that map directly to Jodit configuration options.

Dynamic Props

Can be changed at runtime:

  • disabled - Completely disable the editor
  • readonly - Content visible but not editable

Static Props

Set at initialization (recreate editor to change):

  • height, width - Dimensions
  • theme - 'default' or 'dark'
  • placeholder - Empty state text
  • toolbar, statusbar - UI visibility
  • language, direction - i18n
Props vs Config

Props are convenience shortcuts. For advanced options (custom buttons, plugins, etc.), use the config prop. Props override config values when both are specified.
